Content Refresh Prioritization Using Historical Search and Content Signals

Abstract

This project investigates whether historical search performance and content characteristics can help identify pages that may benefit from content refresh. A content refresh prioritization workflow was developed using page-level search and content features and an interpretable Decision Tree model. The model was compared with a simple baseline scoring approach using a train-test evaluation. The Decision Tree achieved 63.17% accuracy compared with 55.33% for the baseline in the reported experiment. The results are intended as directional decision-support for content teams and do not establish that refreshing a page will causally improve search performance.

Introduction / Problem Statement

Can historical search performance and content characteristics be used to identify pages that may benefit from content refresh? The goal is to support content teams in prioritizing pages for manual review using observed historical search signals.

Data

This project uses the FlyRank internship search-intelligence dataset available through the internship program. The analysis uses page-level observations containing historical search-performance and content characteristics. The analysis focuses on historical observations available in the dataset and uses only information available at the time of the prioritization decision.

Excluded fields:

  • Client identifiers
  • Content identifiers
  • Target-derived or future-window fields that could leak the prediction target
  • Private or identifying information

The excluded fields were removed to keep the analysis public-safe and prevent target leakage.

Methodology

The analysis uses search and content features including search volume, impressions, average position, CTR, word count, content age, and days since last update. The target is whether the observed trend direction is "down". A Decision Tree classifier was evaluated using an 80/20 train-test split. Target-derived fields such as trend direction and trend percentage were excluded from the model inputs to reduce leakage.

Results

Model Accuracy
Baseline Rule 55.33%
Decision Tree 63.17%

The Decision Tree performed better than the baseline in the reported experiment while remaining relatively interpretable.

Limitations

  • The analysis does not establish a causal relationship between refreshing content and improved search performance.
  • Search performance may also be affected by seasonality, marketing activity, competitor activity, and search-engine changes.
  • The available dataset does not capture every factor that may influence content performance.

Ranked Recommendations / Action Playbook

Pages can be prioritized for manual review using historical impressions, time since the last update, and average search position. Higher-priority pages should be reviewed by a human before any refresh decision is made.
